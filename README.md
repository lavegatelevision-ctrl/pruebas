# La Vega Television Android TV

Aplicación Android TV simple que carga la web de WordPress:

- URL inicial: `https://lavegatelevision.com/`
- Navegación con control remoto:
  - `DPAD Arriba/Abajo`: scroll por página.
  - `Back`: retroceder dentro del historial de la web.

## Requisitos

- Android Studio Jellyfish o superior.
- Android SDK 34.

## Ejecutar

1. Abrir el proyecto en Android Studio.
2. Sincronizar Gradle.
3. Ejecutar en un emulador Android TV o dispositivo físico.
