# Beyblade Arena (Android)

Proyecto Android en Kotlin + Jetpack Compose listo para abrirse en Android Studio.

## Qué incluye
- Pantalla de inicio con contenido destacado de Beyblade.
- Navegación inferior con 4 secciones: Inicio, Beys, Batallas y Perfil.
- Sección para agregar tus propios Beyblades con estadísticas personalizadas.
- Tarjetas visuales con estilo moderno Material 3.
- Estructura base para seguir creciendo la app.

## Cómo abrir
1. Abre Android Studio.
2. Selecciona **Open** y elige la carpeta `pruebas`.
3. Espera la sincronización de Gradle.
4. Ejecuta en emulador o dispositivo.

## Requisitos recomendados
- Android Studio Iguana o superior.
- JDK 17.
- Android SDK 34.
